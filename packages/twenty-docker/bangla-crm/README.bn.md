# বাংলা CRM: ইনস্টল ও প্রতিদিনের ব্যবহার

*Read in English: [README.md](README.md)*

বাংলা CRM হলো একটি কাস্টমার রিলেশনশিপ ম্যানেজমেন্ট সফটওয়্যার, যার ইন্টারফেস **শুরু থেকেই বাংলায়**। এতে আছে ব্যক্তি (কন্টাক্ট) ও প্রতিষ্ঠান, সুযোগ (ডিল), কাজ, নোট, ইমেইল ও ক্যালেন্ডার সিঙ্ক, ওয়ার্কফ্লো এবং AI। এটি ওপেন-সোর্স CRM [Twenty](https://github.com/twentyhq/twenty)-এর ওপর তৈরি এবং চলে আপনার নিজের কম্পিউটারে বা নিজের ক্লাউড সার্ভারে। তাই আপনার তথ্য আপনার কাছেই থাকে।

---

## ১. যা যা লাগবে

| | সর্বনিম্ন | প্রস্তাবিত |
|---|---|---|
| কম্পিউটার | Windows 10/11 (64-bit), macOS 14 বা নতুন, অথবা Intel/AMD (x86-64) প্রসেসরের Linux | |
| মেমরি (RAM) | 4 GB | 8 GB বা বেশি |
| খালি জায়গা (ডিস্ক) | 10 GB | 20 GB বা বেশি |
| ইন্টারনেট | প্রথমবার ডাউনলোডের জন্য (প্রায় 1 GB) ও আপডেটের জন্য | |
| Docker | Windows/macOS-এ **Docker Desktop**, Linux-এ Docker Engine | |

- **Windows:** Docker Desktop চলে WSL 2-এর মাধ্যমে। তাই BIOS/UEFI-তে **হার্ডওয়্যার ভার্চুয়ালাইজেশন চালু থাকতে হবে** (সাধারণত নাম থাকে *Virtualization*, *SVM* বা *VT-x*)।
- **Docker Desktop-এর লাইসেন্স:** ব্যক্তিগত ব্যবহার, শিক্ষা এবং ছোট প্রতিষ্ঠানের জন্য Docker Desktop বিনামূল্যে। ছোট প্রতিষ্ঠান মানে ২৫০ জনের কম কর্মী **এবং** বছরে ১ কোটি মার্কিন ডলারের কম আয়। এর চেয়ে বড় প্রতিষ্ঠানকে Docker-এর পেইড সাবস্ক্রিপশন নিতে হবে, অথবা Linux-এ Docker Engine ব্যবহার করতে হবে।
- **Apple Silicon Mac (M1–M4):** বাংলা CRM এখানে Docker Desktop-এর এমুলেশনের মাধ্যমে চলে। কাজ করে, তবে Intel/AMD কম্পিউটারের চেয়ে ধীরে।
- **ARM প্রসেসরের Linux** (যেমন Raspberry Pi বা ARM ক্লাউড সার্ভার): সমর্থিত নয়।

## ২. ইনস্টল করুন

### Windows
1. ডাউনলোড করা `.zip` ফাইলে রাইট-ক্লিক করুন → **Properties** → **Unblock**-এ টিক দিন → **OK**। এতে Windows ইনস্টলারটি আটকে দেবে না।
2. zip-টি একটি স্থায়ী ফোল্ডারে এক্সট্র্যাক্ট করুন, যেমন `Documents\Bangla CRM`। **এই ফোল্ডারটি রেখে দিন।** এতে আপনার সেটিংস (`.env`) ও ব্যাকআপ থাকে।
3. **`Install-Bangla-CRM.cmd`**-এ ডাবল-ক্লিক করুন।
   - Docker Desktop না থাকলে ইনস্টলার নিজেই সেটি ইনস্টল করার প্রস্তাব দেবে। এরপর Windows রিস্টার্ট করুন। Docker Desktop একবার খুলে এর শর্তাবলি মেনে নিন এবং *Engine running* দেখানো পর্যন্ত অপেক্ষা করুন। তারপর আবার `Install-Bangla-CRM.cmd`-এ ডাবল-ক্লিক করুন।
4. অপেক্ষা করুন। প্রথমবার প্রায় 1 GB ডাউনলোড হয় এবং ডাটাবেস তৈরি হয়, এতে ৫–১৫ মিনিট লাগতে পারে। এরপর ব্রাউজারে বাংলা CRM খুলবে, আর ডেস্কটপে **Bangla CRM** নামে একটি শর্টকাট তৈরি হবে।

**ইনস্টলারের অপশন** (অন্য পোর্ট, নেটওয়ার্কে শেয়ার, নির্দিষ্ট ভার্সন): বাংলা CRM ফোল্ডারটি খুলুন, ফোল্ডারের ঠিকানার ঘরে `cmd` লিখে Enter চাপুন। তারপর যেমন চালান:
`Install-Bangla-CRM.cmd -Port 3100`, `Install-Bangla-CRM.cmd -Lan` অথবা `Install-Bangla-CRM.cmd -Version 0.1.0`।

### macOS ও Linux
```bash
bash install.sh
```
অপশন: অন্য পোর্টের জন্য `--port 3100`, অফিস নেটওয়ার্কে শেয়ারের জন্য `--lan`, নির্দিষ্ট ভার্সনের জন্য `--version 0.1.0`।

### ক্লাউড সার্ভার (Ubuntu 22.04 / 24.04, x86-64), HTTPS সহ
1. একটি **x86-64 (Intel/AMD)** সার্ভার নিন (কমপক্ষে 2 GB RAM, ভালো হয় 4 GB)। আপনার ডোমেইনের DNS **A রেকর্ড** সার্ভারের পাবলিক IP-তে সেট করুন।
2. এই ফোল্ডারটি সার্ভারে কপি করুন। SSH দিয়ে ঢুকে ফোল্ডারের ভেতরে চালান:
   ```bash
   sudo bash deploy-cloud.sh crm.example.com you@example.com
   ```
   স্ক্রিপ্টটি যা করে:
   - দরকার হলে Docker ইনস্টল করে।
   - পোর্ট 80/443 খুলে দেয়।
   - Let's Encrypt থেকে বিনামূল্যে HTTPS সার্টিফিকেট নেয়।
   - সোয়াপ ফাইল ও প্রতি রাতের ব্যাকআপ চালুর প্রস্তাব দেয়।
3. **সেটআপ মোড:** শুরুতে শুধু **আপনার নিজের IP ঠিকানা** (যেটি থেকে SSH করেছেন) থেকেই সাইটটি খোলা যায়। এতে অন্য কেউ আগে সাইন আপ করে অ্যাডমিনিস্ট্রেটর হয়ে যেতে পারবে না।
   **এখনই** `https://আপনার-ডোমেইন` খুলে সাইন আপ করুন। তারপর আপনার দলের জন্য সাইটটি খুলে দিন:
   ```bash
   sudo bash bangla-crm.sh finish-setup
   ```
4. আপনার ক্লাউড প্রোভাইডারের নিজস্ব ফায়ারওয়াল বা security group থাকলে সেখানেও **80** ও **443** পোর্ট খুলে দিন।

## ৩. অ্যাপে প্রথম কাজ
1. বাংলা CRM খুলুন। Windows-এ ডেস্কটপের শর্টকাট দিয়ে, নিজের কম্পিউটারে `http://localhost:3000` ঠিকানায়, আর ক্লাউড সার্ভারে `https://আপনার-ডোমেইন` ঠিকানায়।
2. **সাইন আপ করুন।** **প্রথম অ্যাকাউন্টটিই এই ইনস্টলেশনের অ্যাডমিনিস্ট্রেটর হয়।**
3. ইন্টারফেস বাংলায় থাকবে। প্রত্যেক ব্যবহারকারী **সেটিংস → অভিজ্ঞতা → ভাষা** থেকে নিজের ভাষা বদলাতে পারেন।
4. **সেটিংস → সদস্যগণ** থেকে আপনার দলের সদস্যদের আমন্ত্রণ জানান। আমন্ত্রণের ইমেইল পাঠাতে আগে ইমেইল সেটআপ করে নিন (নিচে দেখুন)।

### ইমেইল (SMTP): আমন্ত্রণ ও পাসওয়ার্ড রিসেটের জন্য
অ্যাডমিনিস্ট্রেটর হিসেবে **সেটিংস → অ্যাডমিন প্যানেল → কনফিগ ভেরিয়েবলসমূহ** খুলুন। সেখানে ইমেইল সেটিংস খুঁজে আপনার মেইল সার্ভিসের SMTP তথ্য দিন। উদাহরণ হিসেবে Gmail-এর সেটিংস নিচে দেওয়া হলো। Gmail-এ সাধারণ পাসওয়ার্ড নয়, একটি **App Password** ব্যবহার করুন:
- `EMAIL_DRIVER`: SMTP
- `EMAIL_SMTP_HOST`: `smtp.gmail.com`, `EMAIL_SMTP_PORT`: `465`
- `EMAIL_SMTP_USER`: `you@gmail.com`, `EMAIL_SMTP_PASSWORD`: আপনার app password
- `EMAIL_FROM_ADDRESS`: `you@gmail.com`, `EMAIL_FROM_NAME`: আপনার প্রতিষ্ঠানের নাম

### OpenRouter দিয়ে AI সুবিধা (ঐচ্ছিক)
বাংলা CRM [OpenRouter](https://openrouter.ai)-এর মাধ্যমে AI মডেল ব্যবহার করতে পারে। এর জন্য **আপনার নিজের** OpenRouter কী লাগবে। বাংলা CRM-এর সাথে কোনো কী দেওয়া হয় না।
1. <https://openrouter.ai/keys> থেকে একটি API কী তৈরি করুন।
2. বাংলা CRM-এ **সেটিংস → অ্যাডমিন প্যানেল → AI** খুলে **কাস্টম প্রোভাইডার যোগ করুন**-এ ক্লিক করুন।
3. **প্রোভাইডার** তালিকায় **OpenRouter** থাকলে সেটি বেছে নিন। না থাকলে **কাস্টম প্রোভাইডার**-এ ক্লিক করুন।
4. **লেবেল** ঘরে `OpenRouter`, **API কী** ঘরে আপনার কী, আর **বেস URL** ঘরে `https://openrouter.ai/api/v1` দিন। তারপর **সংরক্ষণ** করুন।
5. নতুন OpenRouter-টি খুলুন। এতে এখনও কোনো মডেল না থাকলে **মডেল যোগ করুন**-এ ক্লিক করুন। **মডেল আইডি** <https://openrouter.ai/models> পাতায় যেমন লেখা আছে হুবহু তেমন দিন (যেমন `:free` দিয়ে শেষ হওয়া কোনো মডেল), সাথে একটি লেবেল দিন। যে মডেলগুলো ব্যবহার করতে চান সেগুলো চালু আছে কি না দেখে নিন।
6. এরপর বাংলা CRM-এ যেখানে AI মডেল বেছে নেওয়ার সুযোগ আছে, সেখানে এই মডেলগুলো দেখা যাবে।

মনে রাখবেন:
- OpenRouter-এর ফ্রি মডেলগুলোতে দৈনিক সীমা আছে। পেইড মডেলের খরচ আপনার OpenRouter অ্যাকাউন্টের ক্রেডিট থেকে কেটে নেওয়া হয়।
- Twenty **২৫ জন পর্যন্ত সদস্যের** ইনস্টলেশনে কাস্টম AI প্রোভাইডার বিনামূল্যে ব্যবহার করতে দেয়। ২৫ জনের বেশি হলে Twenty-র Enterprise কী লাগে।

## ৪. প্রতিদিনের ব্যবহার

| কাজ | Windows (ডাবল-ক্লিক; অপশন দিতে ফোল্ডারে `cmd` খুলে চালান) | macOS / Linux |
|---|---|---|
| চালু করা | `Start-Bangla-CRM.cmd` | `bash bangla-crm.sh start` |
| বন্ধ করা (তথ্য থেকে যায়) | `Stop-Bangla-CRM.cmd` | `bash bangla-crm.sh stop` |
| ব্যাকআপ | `Backup-Bangla-CRM.cmd` | `bash bangla-crm.sh backup` |
| সর্বশেষ ভার্সনে আপডেট | `Update-Bangla-CRM.cmd` | `bash bangla-crm.sh update` |
| নির্দিষ্ট ভার্সনে আপডেট | `Update-Bangla-CRM.cmd -Version 0.2.0` | `bash bangla-crm.sh update --version 0.2.0` |
| ব্যাকআপ থেকে ফেরত আনা | `Restore-Bangla-CRM.cmd` (কোনটি তা জিজ্ঞেস করবে; অথবা ব্যাকআপ ফোল্ডারটি টেনে এর ওপর ছাড়ুন) | `bash bangla-crm.sh restore backups/<তারিখ-সময়>` |
| লগ দেখা | `Logs-Bangla-CRM.cmd` | `bash bangla-crm.sh logs` |
| অবস্থা দেখা | `powershell -ExecutionPolicy Bypass -File bangla-crm.ps1 status` | `bash bangla-crm.sh status` |

কম্পিউটার বন্ধ করার সময় বাংলা CRM চালু থাকলে, পরে Docker Desktop চালু হলে এটিও নিজে থেকে চালু হয়। প্রতিবার কম্পিউটার চালুর পর বাংলা CRM পেতে Docker Desktop-এর সেটিংসে *Start Docker Desktop when you sign in* চালু রাখুন।

### ব্যাকআপ
- প্রতিটি ব্যাকআপ `backups/<তারিখ-সময়>/` নামের একটি ফোল্ডার। এতে থাকে:
  - `database.dump`: ডাটাবেস
  - `files/`: আপলোড করা ফাইল
  - `env.txt`: আপনার সেটিংসের কপি, **এনক্রিপশন কী সহ**
  - `version.txt`: কোন ভার্সনের ব্যাকআপ
- **ব্যাকআপ গোপন রাখুন।** যার কাছে ব্যাকআপ থাকবে, সে আপনার CRM-এর সব তথ্য পড়তে পারবে। ব্যাকআপ অন্য কোনো ডিস্কে বা ব্যক্তিগত ক্লাউড ফোল্ডারে কপি করে রাখুন। একই ডিস্কে রাখা ব্যাকআপ ডিস্ক নষ্ট হলে কাজে আসবে না।
- ক্লাউড সার্ভারে `deploy-cloud.sh` বাংলাদেশ সময় রাত ২:৩০-এ প্রতিদিন ব্যাকআপ নেওয়ার ব্যবস্থা করে দিতে পারে। এতে শেষ ১৪ দিনের ব্যাকআপ থাকে।

### ব্যাকআপ থেকে ফেরত আনা (restore)
restore **বর্তমানের সব তথ্য মুছে** বেছে নেওয়া ব্যাকআপ বসিয়ে দেয়। নিশ্চিত করতে `RESTORE` লিখতে হবে। কিছু বদলানোর আগে বর্তমান তথ্যের একটি **নিরাপত্তা ব্যাকআপ** নেওয়া হয়। ব্যাকআপটি প্রথমে একটি অস্থায়ী ডাটাবেসে বসানো হয়, তাই সেখানে সমস্যা হলে আপনার বর্তমান তথ্য অক্ষত থাকে। ব্যাকআপটি অন্য এনক্রিপশন কী দিয়ে তৈরি হলে বাংলা CRM ব্যাকআপের কী-তে বদলে নেয় এবং আগের সেটিংস `.env.before-restore-<তারিখ-সময়>` ফাইলে রেখে দেয়।

### আপডেট
আপডেট প্রথমে সর্বশেষ প্রকাশিত ভার্সন খোঁজে। আপনি সর্বশেষ ভার্সনেই থাকলে কিছুই বদলায় না। না থাকলে আগে একটি ব্যাকআপ নেয়, তারপর নতুন ভার্সন ডাউনলোড করে চালু করে এবং ডাটাবেস নিজে থেকেই আপগ্রেড করে। **নতুন ভার্সন চালু না হলে এটি নিজে থেকেই আগের ভার্সন ও ব্যাকআপে ফিরে যায়।**

### নতুন কম্পিউটারে নেওয়া, বা নতুন zip খোলা
আপডেটের জন্য নতুন zip লাগে **না**। আপনার বর্তমান ফোল্ডারে Update চালালেই হবে। নতুন কম্পিউটার বা নতুন ফোল্ডারে নিতে চাইলে:
1. Docker ইনস্টল করুন এবং বাংলা CRM নতুন ফোল্ডারে এক্সট্র্যাক্ট করুন।
2. পুরোনো ফোল্ডার থেকে **`.env`** ফাইল ও **`backups`** ফোল্ডার নতুন ফোল্ডারে কপি করুন (অথবা কোনো ব্যাকআপের `env.txt`-এর নাম বদলে `.env` করুন)।
3. ইনস্টলার চালান, তারপর সর্বশেষ ব্যাকআপটি **Restore** করুন।

একই কম্পিউটারে পুরোনো `.env` ছাড়া নতুন ফোল্ডার থেকে ইনস্টলার চালু হবে না, কারণ তাতে বিদ্যমান তথ্য অপাঠযোগ্য হয়ে যেত।

## ৫. অফিস নেটওয়ার্কে শেয়ার করা
Windows-এ `-Lan` আর macOS/Linux-এ `--lan` দিয়ে ইনস্টলার চালান। তখন অন্য কম্পিউটার থেকে `http://<এই-কম্পিউটারের-IP>:3000` ঠিকানায় খোলা যাবে। ঠিকানাটি ইনস্টলার দেখিয়ে দেবে। আপনার রাউটার যিনি দেখাশোনা করেন, তাঁকে এই IP ঠিকানাটি কম্পিউটারটির জন্য সংরক্ষণ (reserve) করে দিতে বলুন, যাতে এটি না বদলায়। যে কম্পিউটারে বাংলা CRM চলছে, সেটি চালু রাখতে হবে।
Windows-এ অন্যরা সংযোগ না পেলে *Windows Defender Firewall*-এ **Private** নেটওয়ার্কের জন্য **Docker Desktop**-কে অনুমতি দিন।

## ৬. সমস্যা ও সমাধান
| সমস্যা | করণীয় |
|---|---|
| "Port 3000 is in use or reserved" | অন্য পোর্ট দিয়ে ইনস্টলার চালান: `Install-Bangla-CRM.cmd -Port 3100` / `bash install.sh --port 3100`। |
| প্রথমবার চালু হতে অনেক সময় লাগছে | এটি স্বাভাবিক। ডাটাবেস তৈরি হচ্ছে, ধীর কম্পিউটারে ~১৫ মিনিট পর্যন্ত লাগতে পারে। |
| "Docker is not running" | Docker Desktop খুলুন, *Engine running* না দেখানো পর্যন্ত অপেক্ষা করুন, তারপর আবার চেষ্টা করুন। |
| Docker Desktop বলছে ভার্চুয়ালাইজেশন চালু নেই | BIOS/UEFI সেটিংসে *Virtualization* / *SVM* / *VT-x* চালু করে কম্পিউটার রিস্টার্ট করুন। |
| ডাউনলোডে *denied* / *not found* দেখাচ্ছে | ওই ভার্সনটি নেই। <https://github.com/Rabbit-s-Hat/bangla-crm/releases> পাতার *Releases* থেকে একটি ভার্সন নম্বর নিন। |
| ক্লাউড সাইটে "being set up" লেখা আসছে | আপনি যে IP থেকে ইনস্টল করেছিলেন, এখন সেই IP-তে নেই। সেই সংযোগ থেকে সাইন আপ করুন, অথবা `sudo bash bangla-crm.sh finish-setup` চালান। |
| অন্য কোনো সমস্যা | লগ দেখুন (উপরের টেবিল দেখুন) এবং শেষের লাইনগুলো আপনার বাংলা CRM সাপোর্টে পাঠান। |

## ৭. আনইনস্টল
- প্রোগ্রাম বন্ধ করে সরাতে, কিন্তু **তথ্য রেখে দিতে**: এই ফোল্ডারে `docker compose down` চালান।
- **সব তথ্যসহ সবকিছু মুছতে**: `docker compose down -v` চালান। এটি আর ফেরানো যায় না, তাই আগে ব্যাকআপ নিন।
